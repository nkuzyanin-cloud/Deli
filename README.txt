МАРШРУТЫ ДОСТАВОК — PWA

Что умеет:
- добавлять доставки на любые даты;
- редактировать и удалять их;
- сохранять старые дни в разделе «История»;
- отмечать выполненные доставки;
- записывать время начала и завершения рабочего дня;
- считать длительность дня;
- экспортировать CSV для анализа недели/месяца;
- делать полную резервную копию JSON и восстанавливать её;
- работать офлайн после установки.

ВАЖНО:
PWA нельзя полноценно установить прямо из локального file://.
Нужно один раз разместить содержимое этой папки на HTTPS-хостинге.

Самый простой вариант без программирования:
1. Распаковать ZIP.
2. Загрузить папку на любой статический HTTPS-хостинг (например, Netlify Drop / Cloudflare Pages / GitHub Pages).
3. Открыть полученную ссылку в Safari на iPhone.
4. Нажать «Поделиться» -> «На экран Домой».
5. После установки приложение будет открываться отдельно и работать офлайн.

Данные хранятся локально на устройстве в localStorage.
Для переноса на другой телефон используйте «Данные» -> «Резервная копия JSON».

ОБНОВЛЕНИЕ ИНТЕРФЕЙСА
Нижние вкладки: Маршрут / История / Данные.
Кнопка ○ отмечает доставку и записывает время; повторное нажатие снимает отметку.
Меню ••• открывает редактирование и удаление с подтверждением.
Добавление и редактирование открываются в нижней панели.
История показывает прогресс, начало/конец и длительность дня.

КАК ОБНОВИТЬ БЕЗ ПОТЕРИ ДАННЫХ
1. На всякий случай создайте JSON-копию в старой версии.
2. Замените файлы на ТОМ ЖЕ сайте и по тому же пути.
3. Откройте приложение с интернетом и затем откройте повторно, если ещё видна старая версия.
Ключ localStorage courier_routes_v3 и формат version:3 не изменены.
Другой домен/порт или другой браузер используют другое локальное хранилище —
в таком случае восстановите JSON. Данные не синхронизируются между устройствами.

Новых библиотек, шрифтов, сетевых API или серверных зависимостей нет.
Дедлайны показываются в местном времени телефона. Просроченные выделены текстом.
Предусмотрены safe area, reduced motion, VisualViewport для клавиатуры и 16px поля.
Физический iPhone и настоящая клавиатура Safari требуют проверки на устройстве.
