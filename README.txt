МАРШРУТЫ ДОСТАВОК — ОБНОВЛЁННОЕ PWA

КАК ПОЛЬЗОВАТЬСЯ
• Домашний адрес укажите один раз: меню ••• в шапке → Домашний адрес.
• Свайп влево открывает следующий день, вправо — предыдущий.
• Нажатие на дату открывает календарь; в меню есть переход к сегодняшнему дню.
• Две записи 🏠 закреплены в начале и конце каждого маршрута.
• Отметьте «Вышел из дома»: автоматически запишется начало дня.
• Отметьте «Вернулся домой»: запишется завершение и появится панель с длительностью.
  При незакрытых доставках приложение спросит подтверждение.
• Снятие отметки возвращения отменяет завершение. Снятие выхода отменяет
  начало и завершение (если день завершён, потребуется подтверждение).
• Все обычные доставки используют 📦 и добавляются между домашними этапами.
• Меню ••• в шапке → Изменить порядок: тяните за ≡ или нажимайте ↑ / ↓.
  Домашние этапы не перемещаются. Изменения сохраняются сразу.
• В меню выполненной записи можно исправить дату и время.
• История содержит дни с доставками или отмеченным выходом/возвращением.
  Простой просмотр пустой даты не сохраняет её и не создаёт запись в истории.
• Домашние этапы не входят в счётчик доставок.

ДАННЫЕ
Работают CSV, JSON-копия, восстановление JSON, локальное сохранение и офлайн.
Ключ localStorage courier_routes_v3 и версия JSON version:3 сохранены.
Добавлены необязательные поля настроек и домашнего адреса рабочего дня.
Старые JSON-копии поддерживаются. Существующие времена не пересчитываются.
Точная старая встроенная запись «Выйти из ЖК «Видный город»» переносится
в домашний старт; её исходные поля остаются в JSON в homeStartSource.
Пользовательские записи, включая названия «Дом», не удаляются автоматически.
При необходимости удалите дублирующую обычную доставку через её меню.

CSV сохраняет прежние столбцы и добавляет record_type:
  delivery — обычная доставка;
  home_start — выход;
  home_finish — возвращение.
Для подсчёта заказов используйте строки delivery.
Домашний адрес рабочего дня фиксируется при выходе; последующее изменение
адреса по умолчанию не изменяет ранее зафиксированные адреса.
Новых библиотек, шрифтов или серверных зависимостей нет.

ОБНОВЛЕНИЕ
1. Сделайте JSON-копию в старой версии.
2. Замените файлы на том же HTTPS-сайте по тому же пути.
3. Откройте приложение с интернетом. Если видна старая версия, закройте
   и откройте снова после обновления.
Другой домен/порт или другой браузер используют отдельное localStorage:
для переноса потребуется импорт JSON. Данные между устройствами не синхронизируются.

УСТАНОВКА
Разместите содержимое архива на статическом HTTPS-хостинге.
В Safari на iPhone: Поделиться → На экран Домой.
После первого открытия приложение доступно офлайн.
Не устанавливается полноценно через file://.
