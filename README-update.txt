Курьерская PWA — обновление 32

КАК ОБНОВИТЬ
1. Скачайте JSON-копию в настройках приложения.
2. Распакуйте ZIP и замените index.html и sw.js в корне Deli.
   Пути сохранены. manifest.webmanifest и основную папку icons/ оставьте.
   README-update.txt — инструкция, её публикация необязательна.
3. Дождитесь публикации GitHub Pages. Откройте PWA с интернетом,
   закройте и снова откройте. В настройках должна быть версия 32
   и сообщение «Кэш приложения готов».
4. Не очищайте данные сайта и не переустанавливайте приложение.

Эта версия включает предыдущее удаление встроенной карты.
Если day-map.js и day-map.css ещё остались в корне, их можно удалить.
map-lab/ возвращать не нужно. Других удалений для версии 32 нет.

СОГЛАСОВАННЫЕ ДЕСЯТЬ ИЗМЕНЕНИЙ
1. Нижняя кнопка статистики в завершённом дне убрана.
2. Постоянная подсказка про удержание записи убрана.
3. Начальный и конечный этапы — компактные «Начало работы» и
   «Конец работы», без домашнего адреса и повторных подписей.
   Отметки выполняются прежними круглыми кнопками. Новые кнопки
   начала/завершения не добавлены. Время можно исправлять нажатием
   на отмеченную строку.
4. Домашний адрес убран из настроек. Прежние адреса в данных сохранены.
5. SVG центрированы внутри серых кружков; область нажатия сохранена.
6. В новой записи — список «Тип адреса»: доставка, склад,
   из постоянных адресов. Выбор постоянного места находится сверху.
   Сохранённые остановки прежнего типа доступны для редактирования;
   их тип и учёт в статистике сохраняются.
7. Дата и срок доставки — два отдельных поля в одной строке.
8. История показывает четыре записи; «Ещё» раскрывает следующие четыре.
   Смена периода начинает список с четырёх. Итоги, график и экспорт
   рассчитываются по полной базе, независимо от раскрытых строк.
9. Короткие анимации отметки, прогресса, перехода к следующей остановке,
   нажатия кнопок и завершения. Данные меняются без ожидания анимации.
   Настройка уменьшения движения учитывается.
10. У текущей остановки — деликатный голубой край и мягкая тень.
    Постоянного пульсирования нет.

ДАННЫЕ И РАБОЧИЕ ФУНКЦИИ
Ключ courier_routes_v3 и формат JSON version: 3 сохранены.
Идентификаторы начального и конечного этапов сохранены для совместимости
с прежними расходами. Существующие дни, адреса, паузы, отметки и расходы
не очищаются. Склад, остановки и рабочие этапы не считаются доставками.
Расчёт рабочего времени и расходов сохранён.
Обычные переходы в Google/Яндекс Карты, звонки и WhatsApp остаются.
Встроенная карта и внешние API не возвращены.

ВЫПОЛНЕННЫЕ ПРОВЕРКИ
Chromium, мобильный размер 375×812; также ширины 320, 430 и 768 px.
- Загрузка прежней тестовой базы без изменения её записей.
- Точное совпадение центров SVG и кружков; области отметки 44×44 px.
- Отсутствие горизонтальной прокрутки на проверенных ширинах.
- Новая форма, дата и срок рядом, выбор сохранённого адреса и контакта.
- Адрес склада по умолчанию, создание, редактирование, перенос, удаление.
- Редактирование прежней остановки без смены типа.
- Сохранение настроек без удаления старого домашнего адреса из данных.
- История 4 → 8 → остальные; подпись «Ещё», смена периода;
  полный график и показатели при свёрнутой истории.
- Начало работы, расход, перерыв, продолжение, отметки и завершение;
  исправление времени начала, правильный счётчик клиентских доставок.
- Отметка и снятие отметки, перезагрузка; независимость контактов
  от редактора и статуса; центрирование суммы проезда.
- Экспорт JSON и восстановление этой копии с точным сравнением базы.
- Обновление кэша 31 → 32, удаление старого кэша, сохранность данных.
- Офлайн-запуск, редактирование, отметки и перезагрузка;
  манифест и иконки находятся в новом кэше.
- Ссылки Google/Яндекс; отсутствие запросов к API встроенной карты.
- Уменьшение движения и визуальный осмотр основных изменённых экранов.
Ошибок JavaScript в выполненных сценариях нет.

ОГРАНИЧЕНИЯ
На физическом iPhone и в Safari эта версия не проверялась.
Настоящая клавиатура iOS и системные переходы в звонок/WhatsApp
требуют проверки на устройстве.
