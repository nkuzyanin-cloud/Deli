# Проверки тестовой сборки 3

Проверено 9 октября 2026. Это отдельная map-lab/, а не повторная проверка
всех функций рабочей PWA. Основные index.html, sw.js, day-map.js и day-map.css
сохранены с прежними SHA-256.

## Данные и алгоритм

- 20 409 адресов в 47 частях; проверены количество, уникальность OSM ID,
  хеши частей и соответствие указателя улиц содержимому файлов.
- Максимальная адресная часть 24 085 байт, ядро 8 234 974 байта. Все файлы
  из манифеста меньше 25 MiB. Реальная загрузка на GitHub — со стороны пользователя.
- 298 548 узлов и 290 312 пешеходных сегментов сохранены.
- 87 объединённых станций, 47 связей пересадок после объединения платформ
  и общего участка ветвей линии 4. Источник каждой пересадки — relation OSM.
- Синтетический тест: рядом стоящие платформы разных линий не соединяются
  без явной связи; направление поездки сохраняется; ожидание увеличивает время.
- Реальная поездка ВДНХ → Парк культуры использует пересадку. Сумма пешего
  времени, поездов, переходов, входа/выхода и ожидания совпадает с общим временем.
- Для короткого пути Тверская → Петровка выбран пеший вариант; неверные
  параметры отвергаются. Пересечение нарисованных дорог не создаёт перекрёсток.
- Node на этой машине: инициализация 341 мс, расчёт 88 мс. Это не результат iPhone.

## Браузер

Chromium 153, мобильный viewport 375×812; также 320, 430 и 768 px.

- Новый запуск выбирает смешанный режим. Явный выбор пешего режима сохраняется.
- Поиск настоящих адресов, неизвестный адрес, ручная точка, изменение подписи,
  перестановка, удаление и перезагрузка с сохранением точек.
- Маршрут по реальным путям метро, пересадка между линиями, список этапов,
  раздельные времена. Короткий путь может остаться пешим.
- Нет горизонтального overflow на проверенных ширинах, включая открытые параметры.
- Панорамирование/щипок не ставят точку; одиночное касание в режиме выбора ставит.
- Zoom при обычной CPU и desktop-throttling 4×; это не измерение реального iPhone.
- Полная перезагрузка без сети и повторный смешанный расчёт.
- Офлайн-поиск ранее не открывавшегося адреса после обновления версии.
- JSON-импорт сохраняет только адреса; клиенты, телефоны и комментарии не сохраняются.
- Диагностика не содержит адресов/координат, содержит positive offlineReady,
  количество пересадок, загруженных адресных частей; кэш поиска не больше 4 частей.
- Отдельно проверено вытеснение LRU: офлайн-поиск загрузил 11 разных частей,
  в кэше осталось 4. Устаревший результат асинхронного поиска не заменяет новый запрос.
- Reduced motion и форма при высоте окна 420 px. Не эмуляция настоящей клавиатуры iOS.
- Ошибок JavaScript и запросов к внешним картографическим сервисам не зарегистрировано.
- Реальный service worker 2 → 3: сохранены старые точки, рабочая база и корневой
  кэш PWA. Новый кэш содержит все 49 файлов данных и манифест. Пешее время старого
  маршрута осталось прежним; новые адреса доступны без сети.
- Неполная загрузка (404 у адресных частей): новый SW не активируется, версия 2
  продолжает работать офлайн. После возврата частей обновление до 3 проходит успешно.
- Визуально просмотрен мобильный экран с картой, пересадкой и списком этапов.

## Границы результата

Физический iPhone / Safari для версии 3 не проверялись. Ваш офлайн-тест версии 2
не считается проверкой версии 3. FPS, пиковая RAM, GPU/Worker memory, нагрев
и расход батареи не измерены. Числовые буферы графа — около 19,4 MB; это не вся RAM.

Времена перегонов, пересадок и входа/выхода — модельные, без калибровки расписанием.
Пеший подход/доступность входов зависят от полноты OSM. Подземный переход показан
как связь, а не восстановленный коридор. Вне тестовой зоны, автобусы, МЦД и МЦК
не поддерживаются. Кандидаты ограничены пятью станциями в радиусе 2,3 км.
