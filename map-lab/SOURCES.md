## Покрытие

Тестовая рамка `[minLon, minLat, maxLon, maxLat]`:
`[37.545, 55.720, 37.685, 55.840]`.
Не вся Москва, не вся Московская область, не гарантированно все адреса в рамке.
Объекты карты у края могут частично выходить за рамку; пеший граф не выходит.

| Данные | Количество |
| --- | ---: |
| Адресные объекты | 20 409 |
| Узлы геометрии / графа | 298 548 |
| Доступные пешие участки | 290 312 |
| Линии дорог и проходов для отрисовки | 101 431 |
| Полигоны зданий, зелени, воды | 45 717 |
| Исходные записи станций / платформ метро | 182 |
| Направленные связи перегонов метро | 160 |
| Станции после объединения платформ/ветвей | 87 |
| Двунаправленные связи пересадок после объединения | 47 |
| Пространственные адресные части (сетка 2 км) | 47 |

Адреса берутся из `addr:*`; возможны неполнота, альтернативное написание и
приблизительная точка здания вместо входа. Совпадающие подписи и населённый
пункт дедуплицируются, входы имеют приоритет. Уличная сеть соединяется по
идентификаторам OSM-узлов, не по простому пересечению нарисованных линий.

Метро использует отношения `route=subway`, порядок остановок и связную
геометрию путей. Пересадки только из совместного членства в `stop_area` /
`stop_area_group`; близость станций сама по себе перехода не создаёт.
Схема групп: [OSM Metro Mapping](https://wiki.openstreetmap.org/wiki/Metro_Mapping).
Входы берутся из узлов `railway=subway_entrance` соответствующего stop_area.
Ветви линии 4 (4 и 4А) на общем участке объединены без фиктивной пересадки.
Расписаний и реальных времён перегонов в сборке нет. Скорость, стоянки,
вход/выход, ожидание и пересадки — явные параметры экспериментальной модели.
Геометрия пересадки — связь платформ, не точная карта подземного коридора.

Адресные части названы по координатам технической сетки, не по административным
районам. Каталог улиц указывает подходящие части. В RAM распаковываются части
по мере поиска / просмотра; все сжатые части сохраняются в офлайн-кэше на диск.
Ядро геометрии и дорожного графа пока единое: для большой региональной базы
понадобится отдельное пространственное разбиение графа с граничными связями.

## Воспроизведение

Установить Python 3 и сборочную зависимость Pyosmium 4.3.1:

```bash
python -m pip install osmium==4.3.1
python map-lab/scripts/build_data.py Moscow.osm.pbf moscow-source.json
python map-lab/scripts/split_data.py moscow-source.json map-lab/data
node map-lab/scripts/test-v3.cjs
```

Интернет нужен только для получения исходника и сборочного инструмента.
На телефоне используются обычные локальные JS/CSS/JSON-файлы; Pyosmium,
Python, Node, внешние картографические библиотеки и API-ключи не требуются.
Для офлайн-режима нужен HTTPS-хостинг или localhost при разработке.
Для распаковки в браузере используются нативные Compression Streams
(Safari / iOS 16.4+, современный Chromium), без внешней JS-библиотеки.

Если публикуете изменённую производную базу, сохраняйте атрибуцию и
соблюдайте ODbL. Иконки PWA взяты из существующего проекта, не из OSM.
